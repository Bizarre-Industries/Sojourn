# Sojourn v0.2 Pivot Plan

Status: **active**. Author of plan: human + Claude (this file is the handoff).
Reader: Claude Code, autonomous. Execute top-to-bottom unless a council vote
says otherwise. Marker: this file's existence at this path means v0.2 is
the active target. `replan-on-tag.sh` writes the next file (`v0.3-plan.md`)
on the next `v*` tag push.

## What this is

The v0.1 scaffold of Sojourn shipped fake Liquid Glass, a 2479-line
`Panes.swift` god-file, mostly stub panes with demo data, a broken
menu-bar/window mode, and an mpm + chezmoi + defaults backend stack with a
speculative Nix-mode "Phase 2."

v0.2 is a hard pivot. **mpm goes away. Nix never gets added. brew bundle
becomes the single source of truth.** The UI is rebuilt on
`NavigationSplitView` with real `glassEffect` (macOS 26+). Two new
first-class panes (Generations, macOS Features) replicate ~85% of the
nix-darwin promise without ever touching `/nix`. Cask, CI, Sparkle, and
the docs tree all rewrite to match.

## Why (one paragraph each)

**Why drop mpm.** brew bundle in 2026 natively manages 11 ecosystems
(brew, cask, mas, vscode, go, cargo, uv, krew, flatpak, npm, tap). PHP/gem
fall through brew taps (`shivammathur/php`, `sportngin/brew-gem`).
Runtime versions go through `mise` via brew. mpm's value collapsed; one
backend is cheaper than two. ADR-0018 supersedes ADR-0010.

**Why drop Nix entirely.** Verified instabilities on macOS Tahoe 26.x:
mas integration broken via nix-darwin
([nix-darwin#1627](https://github.com/nix-darwin/nix-darwin/issues/1627),
Nov 2025), daemon `objc fork()` crash on early Tahoe builds
([NixOS/nix#13342](https://github.com/NixOS/nix/issues/13342)),
Determinate dropped Intel Mac (3.13.2, Nov 2025), 5–20 GB store, 30 s–5 min
rebuilds for one-package adds, round-tripping config from the UI is hard.
The Nix-exclusive features that aren't covered natively or by brew —
bit-for-bit reproducibility, true atomic system rollback — only matter at
team/CI scale, not for a personal/homelab tool. Sojourn replicates ~85%
of the Generations UX via git-tagged tarball snapshots + `brew bundle
install --cleanup --file=<snapshot>` + `chezmoi apply` + plist restore.
Lix and FlakeHub are real improvements but don't fix the macOS
instability — that's APFS/Apple-Silicon/PAM-rewrite-on-update territory,
not a CLI fork. ADR-0022-rejected captures the decision and the two
conditions that would flip it.

**Why drop the `Backend` protocol abstraction.** Was added speculatively
for "Phase 2 Nix mode." With one backend, it's pure YAGNI overhead. If a
future ADR re-introduces a second backend, refactoring then is cheaper
than carrying a speculative interface now.

**Why macOS 26 floor.** Personal/homelab use, Suhail confirmed. Lets us
use `glassEffect`, the Apple `container` CLI, modern PAM. Adoption is
~52% as of January 2026 (vs Sequoia at ~72% at the equivalent point) but
the user-base of Sojourn is "Suhail's machines + a few homelab folks."
Ship it.

## Hard decisions (locked, don't relitigate)

- macOS 26.0 Tahoe deployment floor in `project.yml` (`MACOSX_DEPLOYMENT_TARGET=26.0`),
  `Info.plist` (`LSMinimumSystemVersion=26.0`), `cask` (`depends_on macos: ">= :tahoe"`),
  Sparkle (`minimumSystemVersion=26.0`).
- Single backend: brew bundle. No mpm. No Nix. No `Backend` protocol.
- Brewfile location in chezmoi source: `<chezmoi-source>/dot_config/sojourn/Brewfile.common`,
  `Brewfile.<hostname>`, `cooldowns.toml`. Layered install:
  `brew bundle install --file=Brewfile.common && brew bundle install --file=Brewfile.<hostname>`.
- Cooldown tiers per Brewfile line type, per-package overrides in
  `~/Library/Application Support/Sojourn/cooldowns.toml`:
  - mas → tier A (0 d)
  - homebrew/core brew → B (7 d)
  - third-party tap brew → C (14 d)
  - homebrew/cask → C (14 d)
  - third-party cask → D (21 d)
  - vscode → D (21 d)
  - cargo / npm / go / uv / krew → E (30 d)
- Sparkle EdDSA + cask hybrid update (ADR-0020). Appcast hosted at
  `https://bizarre-industries.github.io/homebrew-sojourn/appcast.xml`.
  Private key in 1Password vault; CI reads via `op` CLI (service-account
  token in `OP_SERVICE_ACCOUNT_TOKEN` GH secret).
- Replace `AdvisoryService` with `brew vulns` shell-out (ADR-0021).
  [Homebrew/homebrew-brew-vulns](https://github.com/Homebrew/homebrew-brew-vulns)
  provides OSV.dev queries, `--brewfile` mode, `--cyclonedx` and `--sarif`
  outputs.
- Cask `depends_on formula: chezmoi, mas`. Bundle `age` + `gitleaks` per
  ADR-0009 AND `depends_on` them as fallback (belt and suspenders).
- mas integration: surface "open App Store" flow for new (unowned)
  purchases. macOS 14.8.2+ / 15.7.2+ / 26.1+ requires `sudo` for
  `mas install`/`mas upgrade` per CVE-2025-43411. Ship a Touch-ID-gated
  helper, never blanket sudo.
- Containers panel: out of v0.2 scope but stub the navigation entry for
  v0.3. Detection priority when implemented: OrbStack > Apple `container`
  CLI (macOS 26+) > Docker Desktop > Lima > Colima.
- Docs purge ignores the v0.3 redirect window in `DOCS_POLICY.md`. One
  source per Diátaxis quadrant, kill all UPPERCASE redirect files now.

## Source code: file-by-file changes

### Delete

- `Sojourn/Backends/` — entire directory (was the speculative
  `Backend` protocol).
- `Sojourn/Services/MPMService.swift` — replaced by `BrewBundleService`.
- `scripts/publish-homebrew-cask.sh` — replaced by `brew bump-cask-pr`
  in CI.
- `Sojourn/UI/Components/LiquidGlass.swift` — fake `.ultraThinMaterial`
  CSS port. Replaced by real `glassEffect` calls inline; no wrapper
  needed on macOS 26+.

### Add

- **`Sojourn/Services/BrewBundleService.swift`** — actor. Parses
  `brew bundle dump --describe` output. Streams `brew bundle install`
  progress via line-buffered `AsyncThrowingStream<JobLine, Error>`.
  Writes/reads `Brewfile.common`, `Brewfile.<hostname>`. Emits a
  `Brewfile` AST type (lines: `brew "x"`, `cask "y"`, `mas "z", id: 123`,
  `vscode "ms-python.python"`, etc.). Tier-aware update planner reads
  `cooldowns.toml`. Tests: golden Brewfile fixtures under
  `SojournTests/Fixtures/brewfiles/`.
- **`Sojourn/UI/Panes/GenerationsPane.swift`** — list view of numbered
  generations. Each generation = git tag in the chezmoi source repo
  named `sojourn-gen-N` + tarball under
  `~/Library/Application Support/Sojourn/generations/N.tar.zst` containing
  (Brewfile.common, Brewfile.<host>, prefs.toml snapshot, machines.toml
  snapshot, chezmoi state hash). "Rollback to N" runs:
  `brew bundle install --cleanup --file=<snapshot/Brewfile.common>` then
  `<snapshot/Brewfile.host>`, then `chezmoi apply` against the snapshot's
  state, then `defaults import` for plist diffs. Service:
  `Sojourn/Services/GenerationService.swift`.
- **`Sojourn/UI/Panes/MacOSFeaturesPane.swift`** — first-class UI over
  Apple's config knobs that nix-darwin's `system.defaults` would have
  wrapped:
  - Touch ID for sudo: toggle that patches `/etc/pam.d/sudo` to insert
    `auth sufficient pam_tid.so` on the second line. Writes a
    `LaunchAgent` that re-applies on each login because Apple
    `softwareupdate` rewrites `/etc/pam.d/sudo` on minor updates.
    Helper script: `scripts/touch-id-sudo.sh` runs as root via a single
    AuthorizationServices prompt, never blanket sudo.
  - Custom dock: drag-to-reorder editor for `persistent-apps`. Writes
    via `defaults write com.apple.dock persistent-apps -array <plist>`
    + `killall Dock`.
  - Finder defaults: `ShowAllExtensions`, `FXPreferredViewStyle`,
    `ShowPathbar`, `ShowStatusBar`, `_FXSortFoldersFirst`,
    `AppleShowAllFiles`.
  - Trackpad / keyboard repeat (`InitialKeyRepeat`, `KeyRepeat`).
  - Screencapture location and format
    (`com.apple.screencapture location`, `type`).
  - Login window text (`com.apple.loginwindow LoginwindowText`).
  - Hotkey editor for `com.apple.symbolichotkeys.plist` (Spotlight,
    input switching, mission control).
  Service: `Sojourn/Services/MacOSFeaturesService.swift`. Each toggle is
  reversible from the Generations pane.
- **`Sojourn/Services/GenerationService.swift`** — handles snapshot
  create/list/restore. Snapshot includes `defaults read` dumps for the
  macOS Features pane's tracked domains so rollback covers UI changes
  too.

### Rewrite

- **`Sojourn/UI/MainWindowView.swift`** (currently 117-line HStack) →
  `NavigationSplitView` with typed sidebar:
  ```swift
  enum Pane: Hashable, CaseIterable {
    case dashboard, packages, generations, macosFeatures,
         preferences, sync, machines, advisories, jobs, settings
  }
  ```
  `@State var selection: Pane = .dashboard`. Detail view switches on
  `selection`. macOS 26 gets `glassEffect()` for free on the
  `NavigationSplitView` chrome — no manual material overlays.
- **`Sojourn/UI/Panes.swift`** (2479 lines, 14 structs) → split into
  `Sojourn/UI/Panes/<PaneName>Pane.swift`, one file per top-level
  `View` struct. Use `git mv` to preserve history where viable
  (extraction is a manual cut, but commit it as a single
  "refactor: split Panes.swift" commit).
- **`Sojourn/Bootstrap/BootstrapCoordinator.swift`** — drop the mpm
  step. New order: Xcode CLT → Homebrew (signed `.pkg` per ADR-0008,
  not curl|bash) → chezmoi via brew → mas via brew → age via brew
  (fallback to bundled binary) → gitleaks via brew (fallback to bundled
  binary).
- **`Sojourn/Services/PrefService.swift`** (currently 105 lines, only
  handles `~/Library/Preferences/`) — extend to:
  - sandboxed apps under
    `~/Library/Containers/<bundle>/Data/Library/Preferences/`
  - PlistBuddy escape hatch for nested keys defaults can't reach
  - Full Disk Access TCC permission flow surfaced in bootstrap (link
    out to System Settings → Privacy & Security → Full Disk Access)
  - Domain detection from the 8ta4 fixture corpus; ship the list as
    `Sojourn/Resources/preference-domains.json` for offline lookup.
- **`Sojourn/Policy/AdvisoryService.swift`** (92 lines, `refresh()`
  was a no-op) — rewrite as a `brew vulns` shell-out. Parse OSV-format
  JSON. Cache results under
  `~/Library/Caches/Sojourn/advisories.json` with 24h TTL.

- New external dependency added (Brewfile, `Package.swift`, GitHub
  Actions workflow).

## Verification rule (read this before every external claim)

Whenever a step would rely on a third-party tool's current behavior,
flag set, or availability — fetch the upstream docs/release notes
before relying on it. Specifically:
[brew bundle docs](https://docs.brew.sh/Brew-Bundle-and-Brewfile),
[Cask Cookbook](https://docs.brew.sh/Cask-Cookbook),
[Sparkle docs](https://sparkle-project.org/documentation/),
[mas-cli releases](https://github.com/mas-cli/mas/releases),
[brew-vulns](https://github.com/Homebrew/homebrew-brew-vulns),
[Apple `container` CLI](https://github.com/apple/container).

LLM-generated code that compiles and "looks right" can still be wrong.
After writing code that calls an external API, framework, or system
service: write a minimal smoke run BEFORE moving to the next task.
Compilation passing ≠ correctness.
