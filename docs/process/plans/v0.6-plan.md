# Sojourn v0.6 Plan

Status: **implemented on main pending verification; no release tag yet**.
Author: Codex after v0.5 verification. Reader: Codex / Claude Code,
autonomous. Re-open only for regressions or release-artifact verification.

## What this is

v0.6 closes a small update UX gap left after v0.4/v0.5 release hardening:
users could invoke Sparkle from the app menu / menubar, but the Settings
surface only described which updater owned the install. General Settings now
has an explicit update check surface with status copy that distinguishes direct
DMG/Sparkle installs from Homebrew cask installs.

## Scope

- Add a General Settings "Check for Updates…" action wired through `AppStore`.
- Surface update status in General Settings with clear cask-vs-Sparkle copy.
- Keep update behavior source-aware: cask installs stay on Homebrew, direct DMG
  and unknown installs stay on Sparkle.
- Add AppStore unit coverage for cask suppression and direct-DMG Sparkle routing.

## Non-goals

- No release tag or artifact publication.
- No Sparkle dependency or appcast behavior changes.
- No Homebrew cask formula changes.
- No background update scheduler changes.

## Acceptance Criteria

- `make build` passes.
- `make test` passes.
- `make leaks` passes.
- Xcode unit tests pass for `SojournTests`.
- Settings exposes `settings.checkForUpdates` and `settings.updateStatus`
  accessibility identifiers.
- UI continues to call update checks only through `AppStore`.
